# 📊 E-Commerce Sales Analysis and Dashboard

## 📌 Project Overview
The **E-Commerce Sales Analysis and Dashboard** is an interactive Power BI report developed to analyze sales performance, customer trends, product performance, and profitability. The dashboard provides business insights through interactive visualizations, enabling users to monitor key performance indicators (KPIs) and make data-driven decisions.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Track profit and revenue across different categories.
- Identify top-performing products and customers.
- Compare regional and state-wise sales.
- Monitor monthly sales trends.
- Support strategic business decision-making through interactive reports.

---

## 🛠️ Tools & Technologies
- **Power BI Desktop (.pbix)**
- Power Query (Data Cleaning & Transformation)
- Microsoft Excel / CSV Dataset
- Data Modeling

> **Note:** This dashboard was created **without using DAX measures or calculated columns**. All calculations and transformations were performed using **Power Query** and Power BI's built-in visualization capabilities.
